SALES TREND VISUALIZATION USING PYTHON
Project Documentation

1. Introduction

Sales Trend Visualization is a Data Science project developed using Python.
The main objective of this project is to analyze sales data and visualize trends using graphs and dashboards.

This project helps businesses understand:

Monthly sales performance
Regional sales distribution
Category-wise sales
Overall business growth trends

The project uses a Kaggle dataset and tools like:

Python
Pandas
Matplotlib
Seaborn
Streamlit

2. Objectives

The objectives of this project are:

To perform data cleaning on raw sales data
To analyze sales trends
To visualize business insights using charts
To create an interactive dashboard
To improve decision-making using data analysis
